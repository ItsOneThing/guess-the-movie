# 🎬 Guess the Movie

An interactive **“Guess the Movie”** game designed for large-scale student events.

Players compete in teams to identify movies from iconic scenes and images, with questions organized into curated categories covering **Marvel, Disney, Hong Kong cinema, anime, Chinese cinema, European films, and world-famous classics**.

The project focuses on a simple principle:

> **Recognize the scene. Guess the movie. Have fun.**

### ✨ Features

- 🎬 Image-based movie guessing
- 🏆 Team competition
- 🗂️ Curated movie categories
- 🌍 Movies from different countries and film cultures
- ⚡ Fast-paced gameplay designed for live events
- 📱 Responsive interface for different screen sizes
- 🎓 Designed with university student events in mind
